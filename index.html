重构吞吐的重量

在数字链路被冠以各种虚浮词藻的今天，绝大多数使用者真正需要的，无非是稳定受控的并发线程，以及在账单到期时不至于让人困惑的配额体系。“猪的大飞机”这个称谓带着某种略显粗粝的自嘲，正是在提醒我们：无论承载协议的工具名字起得多么轻盈，底层的铜缆、光纤与端口转发始终沉重而真实。

我们将服务还原为透明的指标对比。这里没有不可量化的承诺，只有按照物理规律运行的转发规则。无论你是在工作台上调试远程脚本，还是在深夜里整理跨域文档，数据包理应遵循既定规则，平稳通过。

规则透明

配额明确到千兆字节，不设置隐形阈值。所有数据出入皆有迹可循，杜绝峰值阶段的暗中限流与调度歧视。

协议标准

基于成熟开放的标准通信协议运行，不锁定专有闭源客户端，保障使用者拥有纯粹的工具选择自由。

账目平实

月付与年付提供符合常理的折让，不诱导超出实际需求的预充值，让每一次订阅都对应具体的生产力价值。

接入指南与配置流转

猪的大飞机不提供也不捆绑任何经过篡改的第三方二进制安装包。使用者可以在桌面与移动平台中选用受社区广泛检验的通用开源核心，通过标准订阅链接完成节点下发。

桌面操作系统（Windows / macOS / Linux）

适合多显示器与长时间固定网络办公场景。建议使用具备图形界面的开源路由客户端进行托管。

  1. 在受信任的代码托管仓库下载对应系统的原生发行版本并解压。
  2. 从用户中心复制由系统生成的订阅配置地址（URL）。
  3. 在配置管理面板选择“从 URL 导入”，黏贴地址并执行一次全量拉取。
  4. 选择匹配的规则分流模式，测试节点连通性后启用系统代理。

移动操作系统（iOS / Android）

适用于移动网络与不同无线局域网之间的频繁切换，需重点关注系统的常驻后台策略。

  1. 在系统应用商店或官方分发渠道获取支持通用协议的代理套件。
  2. 通过扫描二维码或长按导入配置链接，解析节点集群信息。
  3. 在系统弹窗中允许创建网络扩展（VPN Profile）并授权密码。
  4. 在设置中开启“按需连接”或“分应用代理”，以节省移动流量消耗。

常见疑问解答

如果当月流量耗尽，服务会如何处理？

数据额度以自然月或账单周期结算。若当月套餐内的数据配额完全耗尽，连接将会暂停转发，直到下一个计费周期自动重置，或者使用者手动订购临时补充数据包。

多设备同时在线是以连接数还是 IP 为准？

配额中的设备数指代同一时刻正在与接入点保持活跃 TCP/UDP 会话的物理终端数量。超过额定设备数的连接请求将被策略性拒绝，已连接设备不受影响。

如何验证订阅链接是否已经更新完毕？

客户端通常会在拉取成功后更新本地时间戳。使用者可在配置列表内查看最新的节点存活状态与延迟数值；若出现节点不可用，可手动执行强制更新。

为什么我们不提供专有的封闭定制客户端？

封闭客户端往往伴随安全审计缺位和系统权限滥用的潜在隐患。坚持基于通用公开协议运作，确保每一位使用者的系统环境纯净，配置流程符合行业通用规范。
